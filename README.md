# Library Manager

A Java-based library management system built with JDBC, following a layered architecture (Model-DAO-Service).

## Overview

Library Manager is a backend application that simulates core library operations, developed to demonstrate solid understanding of Java, SQL, and clean code structure.

## Features

- Create, read, update, and delete book records
- Data persistence with MySQL
- Layered architecture for better maintainability

## Tech Stack

- Java
- JDBC
- Maven
- MySQL

## Project Structure

```
src/main/java/library
├── model      # Domain entities
├── dao        # Data access layer (JDBC)
├── service    # Business logic
└── Main.java  # Entry point
```
